# Library Management System

Система управления библиотекой и выдачей книг, разработанная в рамках курсовой работы по дисциплине "Проектирование и разработка клиент-серверных приложений".  
Проект состоит из серверной части на FastAPI и клиентского одностраничного приложения на Vue.js 3.

## 🚀 Возможности

**Для гостей:**
- Регистрация нового читателя
- Вход в систему и получение JWT-токенов

**Для читателей:**
- Просмотр каталога книг с фильтрацией по названию, автору, жанру, году и ISBN
- Просмотр списка авторов и жанров, поиск по имени
- Детальная информация о книге, включая количество доступных экземпляров
- Просмотр истории своих выдач и текущих активных книг
- Проверка возможности взять ещё книги
- Редактирование собственного профиля и смена пароля

**Для библиотекарей:**
- Все возможности читателя
- Создание и редактирование книг, авторов, жанров
- Управление экземплярами книг: добавление (в т.ч. массовое), изменение статуса и местоположения
- Оформление выдачи книги читателю, приём возврата, продление срока
- Просмотр всех выдач, активных и просроченных, статистика
- Просмотр истории выдач конкретного пользователя и экземпляра
- Поиск пользователей по имени или email

**Для администраторов:**
- Все возможности библиотекаря
- Удаление книг, авторов, жанров, экземпляров
- Полное управление пользователями: создание, удаление, блокировка, назначение и снятие ролей

## 🛠️ Технологический стек

| Компонент          | Технология                                      |
|--------------------|-------------------------------------------------|
| Язык бэкенда       | Python 3.11+                                    |
| Серверный фреймворк| FastAPI                                         |
| База данных        | PostgreSQL                                      |
| ORM                | SQLAlchemy                                      |
| Миграции           | Alembic                                         |
| Аутентификация     | JWT-токены                                      |
| Документация API   | OpenAPI (Swagger UI / ReDoc)                    |
| Клиентский фреймворк | Vue.js 3 (Composition API, Pinia, Vue Router) |
| Стилизация         | Tailwind CSS                                    |
| Архитектура        | Модульный монолит                               |
